# Space Pack

A channel pack for [Retro Cable Box](https://perpetual-static.github.io/retro-cable-box/). NASA mission films: Mercury, Gemini, Apollo, Skylab and the Space Shuttle.

## Install

Ask your agent:

> Install the plugin from perpetual-static/pack-space.

The box adds the channels below and plays the films from archive.org. When a
new release of this repo adds channels, the box adds them in its nightly check.
